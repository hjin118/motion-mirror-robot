# 모션 미러 로봇

스마트폰 카메라로 사람의 자세를 인식해서, 3D 공간의 휴머노이드 로봇이 실시간으로 따라 움직이게 하는 웹 프로그램입니다.

- **바로 쓰기**: https://goodssam012.github.io/motion-mirror-robot/
- **사용 설명서**: https://goodssam012.github.io/motion-mirror-robot/guide.html (내려받은 폴더의 `guide.html`을 열어도 됩니다)

## 웹에서 바로 쓰기

휴대폰 브라우저(Chrome, Safari)로 위 주소를 열고 **시작** → 카메라 **허용**을 누르면 됩니다. 설치가 필요 없고 Wi-Fi든 LTE든 열립니다. PC에서 열었다면 **휴대폰으로 열기**를 눌러 QR 코드로 넘어갈 수 있습니다.

## 내 PC에서 실행

[Node.js](https://nodejs.org/) 18 이상이 필요합니다. 저장소를 내려받은 뒤(Code → Download ZIP, 또는 `git clone`):

1. **`start.bat`을 더블클릭**합니다(Mac/Linux는 `node server.mjs`). 서버가 켜지고 PC 브라우저가 열립니다.
2. 5~10초 뒤 PC 화면 오른쪽 위에 **QR 코드**가 뜹니다.
3. **휴대폰 기본 카메라로 QR을 비추고** 뜨는 링크를 누른 뒤 **시작**을 누릅니다.

- 주소는 `https://….trycloudflare.com` 형식이며 Wi-Fi든 LTE든 열리고 보안 경고도 없습니다.
- 주소는 서버를 켤 때마다 바뀝니다. 검은 서버 창을 닫으면 접속이 끊깁니다.
- 터널에는 `cloudflared`가 필요합니다: `winget install Cloudflare.cloudflared`
- 터널 없이 쓰려면 같은 Wi-Fi에서 `https://<PC IP>:8443`로 접속합니다(보안 경고 → 고급 → 계속).
- PC 웹캠으로만 테스트할 때는 `http://localhost:8080`를 엽니다.

## 로봇 선택

화면 위쪽에서 로봇을 고를 수 있습니다. 마지막으로 고른 로봇은 다음에 열 때도 유지됩니다.

| 로봇 | 특징 |
|---|---|
| 에테르 | 펄 세라믹 몸체에 샴페인 골드 관절, 검은 유리 바이저의 고급 제품 디자인 |
| 팬텀 | 밝은 티타늄 각진 장갑과 붉은 빛 이음새의 스텔스 스타일 |
| 오로라 | 무지갯빛 리퀴드 크롬 몸체, 보랏빛 코어와 머리 뒤 헤일로 링 |
| 가디언 | 어깨 장갑, 스커트 아머, 등 추진기가 달린 거대 메카 스타일 |
| 스트라이커 | 가슴 에너지 코어, 빛나는 건틀릿의 파워드 아머 수트 스타일 |
| 타이탄 | 주황 장갑의 덩치 큰 작업용 |
| 레트로 | 은색 양철 몸체, 주름관 팔다리, 전구 눈과 안테나의 50년대 SF 깡통 로봇 |

새 로봇은 `index.html`의 `ROBOTS` 객체에 항목을 추가하면 됩니다. 모든 로봇은 같은 관절 이름을 쓰므로 비율(`dims`)과 겉모양(`dress`)만 정하면 동작 따라 하기는 자동으로 됩니다.

## 사용 팁

- 몸 전체(머리부터 발까지)가 화면에 들어오도록 휴대폰을 2~3m 떨어진 곳에 세워 두세요.
- 기본은 **전신 모드**로, 머리부터 발까지 전부 보일 때만 로봇이 따라 움직입니다. 일부가 화면 밖으로 나가면 로봇은 멈춰 서고, 어떻게 움직이면 되는지(뒤로 물러나기, 가운데로 이동 등) 안내가 나옵니다. 카메라 미리보기의 뼈대도 빨간색으로 바뀝니다.
- **상반신 모드** (설정): 앉아서 쓰거나 휴대폰이 가까울 때 켜세요. 머리와 어깨만 보이면 상체와 팔을 따라 하고, 로봇의 다리는 서 있는 자세를 유지합니다. 이 모드에서는 손가락도 인식해서, 손을 펴면 로봇의 집게 손이 벌어지고 주먹을 쥐면 오므라듭니다(카메라 미리보기에 손가락 뼈대가 노란색으로 표시됨).
- **거울 모드**: 켜면 로봇이 거울처럼 움직입니다(전면 카메라 기본값).
- **손목**: 손을 펴서 손가락이 보이면 손목 꺾기와 손바닥 돌리기도 따라 합니다. 손이 가려지면 손목은 팔과 일직선으로 돌아갑니다.
- **이동 따라가기**: 좌우로 움직이면 로봇도 이동합니다.
- **모델**: Lite가 가장 빠르고, Full/Heavy는 더 정확하지만 느립니다.

## 녹화와 재생

1. **녹화**를 누르면 카메라가 켜지고 녹화가 시작됩니다(최대 3분). 다시 누르면 멈춥니다.
2. **녹화 목록**에서 **재생**을 누르면 위쪽 재생 막대로 재생, 일시정지, 위치 이동, 반복을 조절할 수 있습니다.
3. 재생 중에 로봇을 바꾸면 같은 동작을 다른 로봇으로 볼 수 있습니다.
4. **영상**을 누르면 지금 고른 로봇이 그 동작을 처음부터 끝까지 재생하고, 그 모습이 영상 파일로 만들어집니다. 녹화 길이만큼 시간이 걸리며, 만드는 동안 드래그로 시점을 바꾸면 영상에도 그대로 담깁니다. 끝나면 미리보기와 함께 **영상 저장**이 나오고, 휴대폰에서는 **공유 · 사진에 저장**으로 갤러리에 바로 넣을 수 있습니다.
   - 형식: 지원되면 MP4(아이폰 Safari, 최신 Chrome), 아니면 WebM. 긴 쪽 최대 1280px, 30fps.
5. **파일**을 누르면 동작 데이터(.json)가 저장되고, **파일 불러오기**로 다른 기기에서도 재생할 수 있습니다.

녹화 목록에는 영상이 아니라 관절 좌표만 저장하므로 용량이 작습니다. 녹화 목록은 이 브라우저에만 저장되므로, 남겨 두고 싶은 동작은 파일로 저장해 두세요.

## 구조

| 단계 | 기술 |
|---|---|
| 포즈 인식 | MediaPipe Pose Landmarker (관절 33개, 3D 월드 좌표) |
| 손가락 인식 | MediaPipe Hand Landmarker (손마다 관절 21개, 상반신 모드에서만) |
| 떨림 제거 | One Euro Filter |
| 리타게팅 | 몸통/머리는 좌표축 기반 회전, 팔다리는 뼈 방향 정렬(swing) |
| 렌더링 | Three.js (직접 모델링한 로봇, 발 접지 보정) |

모든 처리는 브라우저 안에서 이루어지며 영상은 어디로도 전송되지 않습니다.
