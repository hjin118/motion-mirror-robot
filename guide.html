01무엇인가요

모션 미러 로봇은 카메라 영상에서 사람의 관절 33개를 실시간으로 찾아내고, 그 자세를 3D 휴머노이드 로봇에 옮기는 웹 프로그램입니다. 앱을 설치할 필요 없이 휴대폰이나 PC 브라우저에서 바로 동작합니다.

  • 실시간 따라 하기: 팔, 다리, 몸통, 고개, 손목(꺾기와 손바닥 돌리기) 움직임을 로봇이 그대로 따라 합니다.
  • 로봇 6종: 디자인이 다른 로봇을 골라 쓸 수 있습니다.
  • 전신 · 상반신 모드: 서서 온몸으로, 또는 앉아서 상체만으로 쓸 수 있습니다.
  • 녹화 · 재생 · 영상 저장: 동작을 녹화해 다른 로봇으로 다시 보고, 영상 파일로 저장할 수 있습니다.

02시작하기

두 가지 방법이 있습니다. 대부분은 웹으로 바로 쓰기가 가장 간단합니다.

추천웹으로 바로 쓰기

  1. 휴대폰으로 위의 QR 코드를 비추거나 아래 주소를 엽니다.
    goodssam012.github.io/motion-mirror-robot
  2. 화면 아래 시작을 누릅니다.
  3. 카메라 권한을 묻는 창이 뜨면 허용을 누릅니다.

설치, 회원가입이 필요 없고 Wi-Fi든 LTE든 열립니다.

PC내 컴퓨터에서 실행하기

  1. Node.js 18 이상을 설치합니다.
  2. 저장소에서 Code → Download ZIP으로 내려받아 압축을 풉니다.
  3. Windows는 start.bat을 더블클릭, Mac/Linux는 폴더에서 node server.mjs를 실행합니다.
  4. PC 브라우저가 열리고, 잠시 뒤 오른쪽 위에 뜨는 QR 코드를 휴대폰으로 비춥니다.

내 컴퓨터에서 실행할 때 알아 둘 점

  • 휴대폰은 보안 연결(HTTPS)에서만 카메라를 쓸 수 있습니다. 서버는 이를 위해 두 가지 주소를 준비합니다.
    • 터널 주소 https://….trycloudflare.com: 어떤 네트워크에서도 열리고 보안 경고가 없습니다. cloudflared가 필요합니다.
    • 같은 Wi-Fi 주소 https://<PC IP>:8443: 보안 경고가 뜨면 고급 → 계속을 누릅니다.
  • cloudflared 설치 (Windows): 
    winget install Cloudflare.cloudflared
  • PC 웹캠만으로 테스트할 때는 http://localhost:8080을 엽니다.
  • 검은 서버 창을 닫으면 접속이 끊깁니다. 터널 주소는 서버를 켤 때마다 바뀝니다.
Git을 쓴다면 ZIP 대신 이렇게 받아도 됩니다. 
git clone https://github.com/goodssam012/motion-mirror-robot.git

03화면 구성

  1. 1
    상태 표시: 대기 중, 추적 중(초당 처리 횟수), 녹화 중, 전신이 보이지 않음 등을 알려 줍니다.
  2. 2
    로봇 선택: 옆으로 밀어서 로봇을 고릅니다. 마지막 선택은 다음에도 유지됩니다.
  3. 3
    3D 화면: 한 손가락(마우스) 드래그로 시점 회전, 두 손가락 핀치(휠)로 확대·축소합니다.
  4. 4
    카메라 미리보기: 인식된 뼈대가 표시됩니다. 청록색이면 정상, 빨간색이면 몸이 화면을 벗어난 상태입니다.
  5. 5
    아래 버튼: 시작/정지, 녹화, 녹화 목록, 설정. PC에서 열면 휴대폰으로 열기(QR 코드)도 나옵니다.

04카메라 앞에 서기

  1. 휴대폰을 허리 높이쯤에 세워 둡니다. 컵이나 책에 기대 두면 편합니다.
  2. 2~3m 뒤로 물러나 머리부터 발끝까지 화면에 들어오게 섭니다.
  3. 몸 전체가 보이면 0.3초 뒤부터 로봇이 따라 움직입니다.

안내 메시지가 뜰 때

몸의 일부가 화면을 벗어나면 로봇은 제자리에 멈추고 위쪽에 안내가 나옵니다. 안내대로 움직이면 다시 따라 합니다.

안내이렇게 하세요
카메라 앞에 서 주세요사람이 인식되지 않은 상태입니다. 화면 안으로 들어오세요.
너무 가까워요몇 걸음 뒤로 물러나세요.
화면 밖으로 벗어났어요화면 가운데로 옆걸음 하세요.
발이 보이지 않아요뒤로 물러나거나 휴대폰을 낮게 두세요.
머리가 잘렸어요뒤로 물러나거나 휴대폰을 조금 위로 향하게 하세요.
어깨가 보이지 않아요 (상반신 모드)휴대폰에서 조금 떨어져 머리와 양쪽 어깨가 보이게 하세요.
잘 인식되게 하려면 밝은 곳에서, 배경과 구분되는 옷을 입고, 카메라를 정면으로 마주 보세요. 헐렁한 옷이나 역광은 인식을 흔들리게 합니다. 손목까지 따라 하게 하려면 손을 펴서 손가락이 카메라에 보이게 하세요. 손이 작게 보이거나 가려지면 손목은 팔과 일직선으로 돌아갑니다.

손가락으로 집게 손 움직이기 (상반신 모드)

로봇의 손은 손가락 두 개와 엄지로 된 집게 손입니다. 상반신 모드에서는 손가락 마디까지 인식해서 손 모양을 따라 합니다.

  • 손을 펴면 집게가 V자로 벌어지고, 주먹을 쥐면 집게가 오므라듭니다. 중간 정도로 쥐면 그만큼 반쯤 닫힙니다.
  • 손바닥 방향(위·아래·옆)과 손목 꺾기도 손가락 인식으로 더 정확하게 따라 합니다.
  • 카메라 미리보기에 손가락 뼈대가 노란색으로 표시되면 손이 인식된 것입니다.
  • 휴대폰에서 1m 안팎으로 앉아, 손바닥이나 손등이 카메라에 보이게 하세요.
  • 처음 켤 때 손 인식용 AI 모델(약 8MB)을 한 번 더 내려받습니다.
  • 전신 모드에서는 손이 작게 보여서 손가락 인식을 쓰지 않으며, 집게는 살짝 오므린 자세를 유지합니다.

05로봇 고르기

화면 위쪽에서 로봇을 누르면 바로 바뀝니다. 모든 로봇이 같은 뼈대를 쓰므로 어떤 로봇이든 똑같이 따라 합니다.

로봇특징
에테르펄 세라믹 몸체에 샴페인 골드 관절, 검은 유리 바이저의 고급 제품 디자인
팬텀밝은 티타늄 각진 장갑과 붉은 빛 이음새의 스텔스 스타일
오로라무지갯빛 리퀴드 크롬 몸체, 보랏빛 코어와 머리 뒤 헤일로 링
가디언어깨 장갑, 스커트 아머, 등 추진기가 달린 거대 메카 스타일
스트라이커가슴 에너지 코어, 빛나는 건틀릿의 파워드 아머 수트 스타일
타이탄주황 장갑의 덩치 큰 작업용
레트로은색 양철 몸체, 주름관 팔다리, 전구 눈과 안테나의 50년대 SF 깡통 로봇

06설정

아래 설정 버튼을 누르면 열립니다.

항목설명
상반신 모드앉아서 쓰거나 휴대폰이 가까울 때 켜세요. 머리와 양어깨만 보이면 상체와 팔을 따라 하고, 다리는 선 자세를 유지합니다. 손가락도 인식해서 로봇의 집게 손이 펴고 쥐는 동작을 따라 합니다. 선택은 다음에도 유지됩니다.
거울 모드켜면 거울처럼 움직입니다(내가 오른손을 들면 로봇은 화면 기준 오른쪽 손). 전면 카메라에서는 켜 두는 것이 자연스럽습니다.
이동 따라가기좌우로 걸으면 로봇도 옆으로 이동합니다. 끄면 로봇은 가운데에 머뭅니다.
카메라 전환전면 ↔ 후면 카메라를 바꿉니다. 후면으로 바꾸면 거울 모드가 자동으로 꺼집니다.
AI 모델빠름(Lite)이 기본입니다. 정확(Full), 최고 정확(Heavy)은 더 정확하지만 느리고 처음 내려받는 데 시간이 걸립니다.

07녹화와 재생

  1. 녹화를 누르면 카메라가 켜지고 녹화가 시작됩니다. 버튼에 녹화 시간이 표시됩니다(최대 3분).
  2. 다시 누르면 멈추고, 녹화 목록에 저장됩니다.
  3. 목록에서 재생을 누르면 위쪽 재생 막대로 재생·일시정지, 위치 이동, 반복을 조절할 수 있습니다.
  4. 재생 중에 로봇을 바꾸면 같은 동작을 다른 로봇으로 볼 수 있습니다.

삭제는 삭제를 누른 뒤 정말 삭제?를 한 번 더 누르면 됩니다.

녹화 목록은 지금 쓰는 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 기기에서 열면 보이지 않습니다. 남겨 두고 싶은 동작은 파일이나 영상으로 저장해 두세요.

08영상으로 저장

녹화한 동작을 로봇이 움직이는 영상 파일로 만듭니다. SNS에 올리거나 친구에게 보낼 때 쓰세요.

  1. 영상에 쓸 로봇을 먼저 고릅니다.
  2. 녹화 목록에서 원하는 녹화의 영상을 누릅니다.
  3. 로봇이 동작을 처음부터 끝까지 재생하는 동안 영상이 만들어집니다. 녹화 길이만큼 걸립니다.
  4. 끝나면 미리보기가 나옵니다. 영상 저장으로 내려받거나, 휴대폰에서는 공유 · 사진에 저장으로 갤러리에 바로 넣습니다.
  • 만드는 동안 화면을 드래그해 시점을 바꾸면 그 카메라 움직임도 영상에 담깁니다.
  • 형식은 지원되면 MP4(아이폰 Safari, 최신 Chrome), 아니면 WebM입니다. 긴 쪽 최대 1280px, 30fps.
  • 영상 왼쪽 아래에 로봇 이름과 녹화 이름이 들어갑니다.
만드는 동안 화면을 켜 두세요. 화면을 끄거나 다른 앱으로 넘어가면 영상 만들기가 멈춥니다.

09동작 파일 주고받기

녹화를 영상이 아닌 동작 데이터(.json)로 저장하면, 다른 기기나 브라우저에서 불러와 어떤 로봇으로든 다시 재생할 수 있습니다. 영상보다 용량이 훨씬 작습니다.

  • 저장: 녹화 목록에서 파일을 누릅니다.
  • 불러오기: 녹화 목록 아래 파일 불러오기를 누르고 .json 파일을 고릅니다.

10문제 해결

카메라가 켜지지 않아요
  • 카메라 권한을 거부했다면 주소창 왼쪽 자물쇠(또는 설정 → 사이트 설정)에서 카메라를 허용으로 바꾸고 새로고침하세요.
  • 주소가 https://로 시작하는지 확인하세요. 보안 연결이 아니면 카메라를 쓸 수 없습니다.
  • 다른 앱(영상통화 등)이 카메라를 쓰고 있으면 닫고 다시 시도하세요.
  • 카카오톡·인스타그램 안의 브라우저에서는 카메라가 막힐 수 있습니다. 주소를 Chrome이나 Safari에서 여세요.
로봇이 따라 움직이지 않아요
  • 전신 모드에서는 머리부터 발끝까지 전부 보여야 합니다. 화면의 안내를 따라 물러나거나, 앉아 있다면 상반신 모드를 켜세요.
  • 카메라 미리보기의 뼈대가 빨간색이면 몸이 화면을 벗어난 상태입니다.
  • 녹화 재생 중에는 카메라 대신 녹화된 동작을 따라 합니다. 재생 막대의 ✕로 닫으세요.
움직임이 느리거나 끊겨요
  • 설정에서 AI 모델을 빠름(Lite)으로 두세요.
  • 밝은 곳에서 쓰면 인식이 안정됩니다.
  • 다른 탭과 앱을 닫고, 휴대폰이 뜨거우면 잠시 식힌 뒤 쓰세요.
처음 열 때 오래 걸려요

처음 한 번은 3D 엔진과 AI 모델(수 MB)을 내려받습니다. 두 번째부터는 브라우저에 저장된 것을 써서 빨라집니다. 인터넷 연결이 필요합니다.

영상 저장이 안 돼요
  • 최신 Chrome, Edge, Safari(iOS 14.3 이상)에서 지원합니다. 오래된 브라우저에서는 안내 메시지가 뜹니다.
  • 아이폰에서 영상 저장이 파일 앱으로 가면, 공유 · 사진에 저장 → 비디오 저장을 쓰세요.
  • 만드는 도중 화면이 꺼지지 않게 하세요.
(내 PC 실행) 휴대폰에서 주소가 열리지 않아요
  • QR이 trycloudflare.com 주소가 아니라면 cloudflared가 설치되지 않은 것입니다. winget install Cloudflare.cloudflared로 설치하고 start.bat을 다시 실행하세요.
  • 같은 Wi-Fi 주소(:8443)는 PC 방화벽이나 네트워크 설정(공용 네트워크)에 막힐 수 있습니다. 이럴 때는 터널 주소나 웹 버전을 쓰세요.
  • 검은 서버 창이 켜져 있는지 확인하세요.
(내 PC 실행) QR 코드가 뜨지 않아요
